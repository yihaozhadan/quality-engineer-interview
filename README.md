# MochaJS Interview

This branch has a bunch of [MochaJS](https://mochajs.org) coding practices.

## Problem Statement

As a quality engineer interviewer, I want to implement the MochaJS coding practices for quality engineer interview. So that I can evaluate the candidate's MochaJS skills.

## Implementation

Mocha is a feature-rich JavaScript test framework running on Node.js and in the browser. This branch provides a set of basic MochaJS code blocks based on the MochaJS features.
